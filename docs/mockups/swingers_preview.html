Swingers — preview dell'interfaccia

Bozza per decidere il layout prima del codice. Stesso linguaggio dei pannelli Fairy Tapes: pannello nero a grana fine, riquadri bianchi con il titolo sul bordo, serigrafia maiuscola, ambra per le scelte attive, LED senza alone. Dati di esempio, non mappe vere.

Quello che si vede nel DAW: 520 × 140. FROM → TO, canale, LED MIDI (lampeggia quando passano note), EDIT MAPPING. Sotto, in ambra, gli avvisi (qui: mappa mancante, usata la copia del progetto).
EDIT MAPPING allarga la finestra del plugin a 900 × 600. Percorsi standard grigi tenui attraverso la colonna GM; trascina da una nota a sinistra a una a destra per un cavo diretto (ambra, nasconde il percorso standard); clic destro su una nota a sinistra per staccarla (grigia barrata) o ripristinarla. Note senza corrispondenza: grigie, senza cavo. ALL NOTES mostra tutte le 128.
EDIT MAPS (dalla patchbay): tabella delle 128 note della mappa scelta, nome modificabile, voce GM da menu, stella = preferita. Le mappe incluse (GM) sono in sola lettura: si duplicano.
Lo standalone: lo stesso pannello compatto più la barra file (OPEN MIDI → CONVERT → SAVE) e il resoconto.
